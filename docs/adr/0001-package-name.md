# ADR-0001: Package name

**Status:** Accepted (2026-11-08).

**Decision:** the package is `presidio-deident`: CLI `deident`, import `presidio_deident`, PyPI
`presidio-deident`.

**Why:** the family's tools are named `presidio-hardened-*`, but `presidio-evidence` set the
precedent for a substrate-like tool that others build on. A short name also reads better in
a lab's verification script.
