# ADR-0011: First public release

**Status:** Accepted (2026-11-08).

**Decision:** the first public release is **0.7.0**, not 1.0. The record format
`dataset-release@1` is final from this release (ADR-0009), but the tool is alpha until a design
partner has produced a real release.

The public repository starts from a single commit containing the 0.7.0 tree. The development
history before it lived in a private repository and is summarised in `CHANGELOG.md` (0.1.0 to
0.7.0) and in these ADRs.
